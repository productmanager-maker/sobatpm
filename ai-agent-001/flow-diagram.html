Data yang Mengalir Antar Komponen
Dari Ke Data Format
Sales Telegram Classifier Raw text pesan string
Sheets: Harga LLM Parser + Nego Checker harga, min_order, harga_modal, newmember_diskon dict[str, dict]
Sheets: Partner Partner Enricher tipe_partner, volume_avg, kota, telegram_chat_id dict | None
LLM Agent #1 Rules Engine partner, produk, qty_kg, harga_per_kg, diskon_diminta JSON → dict
Rules Engine LLM Agent #2 + Logger deal enriched: diskon_disetujui, diskon_max_allowed, need_human_approval, total_harga dict

Logger Memory (last_deal) log_row (Sheets row index 1-based) int | None
Manager (1 klik) Approval Handler callback_data: "approve_{deal_id}" / "reject_{deal_id}" string
PDF Builder Sheets: Log + Sales Chat SO number (SO-YYYYMMDD-HHMMSS) + PDF binary str + file
